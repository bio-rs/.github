# bio-rs

[![License: MIT/Apache-2.0](https://img.shields.io/badge/License-MIT%2FApache--2.0-blue.svg)](https://github.com/bio-rs/bio-rs/blob/main/LICENSE-MIT)

`bio-rs` is a Rust-based bio-AI data/tooling engine.

It validates biological data, prepares model-ready inputs, and emits
reproducible JSON contracts across CLI, Python, WASM, local services, and agent
tools.

## Scope

- Local-first validation, tokenization, package checks, and provenance.
- Interface-ready for tools and agents; not a full AI agent.
- Not a hosted platform, training framework, model registry, or complete
  bioinformatics suite.
